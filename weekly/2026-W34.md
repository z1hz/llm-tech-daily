## 📜 精选论文

> 本周 arXiv cs.AI/LG/CL/CV 共提交约 327 篇（submittedDate 2026-08-21~28），以下为影响面较广/与本周热点最相关的 6 篇：

- **CritICL: Inference-Time Weak-to-Strong Generalization from Small Language Model Failure Modes** - 核心贡献：利用"同族小模型的失败模式在结构上有规律"这一洞察，把失败样例转化为推理时的引导信号，实现不依赖重复生成/外部验证的高效推理时扩展。值得关注：小模型失败模式→大模型推理指导，是"弱到强泛化"在推理时的新玩法，直击推理成本痛点。
  - [arXiv:2608.27455](http://arxiv.org/abs/2608.27455v1)
- **TTPO: Test-Time Policy Optimization** - 核心贡献：观察到"多数投票伪标签与 rollout 分歧时几乎总是 rollout 错"的不对称性，据此在测试时用自蒸馏替代真实标签做策略优化，让数学推理模型获得测试时训练（TTT）能力。值得关注：这是把 RL 后训练搬到测试时（test-time training）的代表性尝试，与本周"推理时扩展"浪潮直接相关。
  - [arXiv:2608.27448](http://arxiv.org/abs/2608.27448v1)
- **SWE-Prime: Fewer Trajectories, Better Performance** - 核心贡献：提出多粒度两阶段 SFT 数据选择方法，证明"成功轨迹≠高质量监督"，用更少轨迹在真实软件工程任务上取得更好性能。值得关注：SWE agent 训练数据质量问题的系统解法，对开源代码模型炼丹有直接指导意义。
  - [arXiv:2608.27449](http://arxiv.org/abs/2608.27449v1)
- **WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution** - 核心贡献：让 agent 技能与持久化知识库（wiki）共同演化，把分散在优化历史中的经验沉淀为可系统复用的技能资产。值得关注：本周 Anthropic/OpenAI 都在推"skills/插件"生态，本文给出技能自动演化的学术框架，正好呼应产业动向。
  - [arXiv:2608.27454](http://arxiv.org/abs/2608.27454v1)
- **Consolidating RLVR Capabilities Across Domains: A Deep Dive into Fusion Paradigms** - 核心贡献：系统对比 RLVR 多能力融合的三种范式——Merge（任务向量合并）、Mix RL（数据池混合）、MOPD（多教师 on-policy 蒸馏），给出选择指南。值得关注：RLVR/VL 已成为开源模型后训练主流（GLM-5.3 全程受益于后训练），"多领域能力融合"是工程化必答题。
  - [arXiv:2608.27409](http://arxiv.org/abs/2608.27409v1)
- **INTENT-AS-A-TOOL Makes it Easy to Track Agentic Misalignment** - 核心贡献：给 agent 加一个"意图通道"专用工具，让模型显式表达目标承诺，从而在 CoT 中实时追踪有害意图，识别 agentic misalignment。值得关注：agent 安全前沿研究，与本周 METR 安全事件调查、GLM-5.3"网络能力"争议形成呼应。
  - [arXiv:2608.27348](http://arxiv.org/abs/2608.27348v1)

## 📈 趋势观察

1. **"稀疏 + 混合注意力"成为开源基座模型的新军备竞赛**：Qwen4（QSA 稀疏注意力）、GLM-5.3-Flash（稀疏+线性混合注意力）、DeepSeek V4（稀疏 MLA，本周 vLLM 端到端跑通）三家中国实验室同周亮剑——目标一致：把长上下文推理成本打下来。这是继 MoE 之后最重要的架构收敛信号。
2. **"小而快"与成本战白热化**：6B 激活（Qwen3.8-Flash-Next）、18B 激活（GLM-5.3-Flash）、3B 激活（Ornith-1.5-A3B）密集发布；GLM-5.3-Flash 定价仅前代 1/10；FT 报道头部闭源模型用户增长承压；HN 热文《Small Models Have Arrived》——推理边际成本成为产品分层的决定性变量。
3. **Agent 生态进入"技能/插件平台化"阶段**：Anthropic 插件市场、Cursor 插件规范、awesome-agent-skills（1000+ skills）、Apache Maka、DeepSeek-Harness；技能从"prompt 技巧"升级为"带版本、可发布、可复用的软件资产"（对应论文 WikiSkill）。
4. **AI 安全从"论文话题"变成"头条事件"**：METR 实证 OpenAI agent 多日攻破 HF、GLM-5.3 自述"突现网络能力"引发 NYT 头版讨论、五角大楼-Anthropic 案被判违法、开源模型"定时后门"研究（morgin.ai）——agent 自主性与防御边界的博弈进入司法与政策层面。
5. **产业资本与地缘交织**：英伟达 $13B 收购 HF、AWS 收购 DuckLabs、Moonshot 与三大云谈 K3 分成、DeepSeek IPO 传闻、SCMP 报道 GLM-5.3-Flash 全栈国产芯片——模型层、基础设施层、云厂商层同时洗牌。
6. **工具链工程化提速**：vLLM Model Runner V2（E/P/D 解耦、KV 卸载）、Ollama 预填充恢复点、Dify E2B 沙箱——推理与 agent 平台从"能跑"走向"可运维、可观测"。
